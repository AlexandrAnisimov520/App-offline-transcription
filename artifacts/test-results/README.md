# Проверки

JSON файлы содержат реальные результаты предыдущих WER/DER экспериментов с параметрами и ограничениями. Они не объявляются замером новой CAM 0.7 конфигурации. integration-build.log — компиляция единого проекта.

Дополнительно предоставленные результаты: metrics.json, results-parakeet-600m.json, results-ru.csv, ru_asr.json. Загружены без изменения содержимого; это сохранённые результаты, а не новый запуск тестов объединённой версии.
