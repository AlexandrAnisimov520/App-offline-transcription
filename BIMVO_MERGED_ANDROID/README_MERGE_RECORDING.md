# BIMVO: объединённый Android MVP

Основа: BIMVO_MVP_Android_patch. Перенесена только идея локальной записи через `MediaRecorder` из `Nuclear-IT-hack-BimboTeam-codex-android-app`. Вторые экраны, БД и processing-api не переносились.

## Что добавлено

- Главная BIMVO → «Записать разговор» запрашивает разрешение на микрофон и записывает AAC/M4A на устройстве. Повторное нажатие останавливает и сохраняет запись.
- Запись создаётся во временной папке `cache/voice-capture`, после успешной остановки переносится с хешированием через `AudioImporter.importCaptured` в `files/audio` и регистрируется в **той же SQLite-библиотеке**, что импортированные файлы.
- После завершения сохранения запись появляется в главной и «Записи»; доступны существующие переименование, удаление и реальное прослушивание.
- При отсутствии разрешения, слишком короткой записи или отсутствии места показывается ошибка. Временный файл при неуспехе удаляется.
- В коде исходной BIMVO сохранены UI/дизайн, импорт аудио, проигрывание/переход по таймкодам, JSON, выжимка и другие существовавшие функции.

## Собрать на Windows

Распакуйте ZIP, откройте PowerShell в папке, где находится `gradlew.bat`:

```powershell
$sdk = "$env:LOCALAPPDATA\Android\Sdk"
"sdk.dir=$($sdk.Replace('\','/'))" | Set-Content local.properties -Encoding ASCII
.\gradlew.bat assembleDebug
explorer .\app\build\outputs\apk\debug
```

Это создаст debug APK, только если Android SDK и необходимые Build Tools установлены.

## Проверка на телефоне

1. Запустите BIMVO, выберите демо-доступ при необходимости и перейдите на главную.
2. Нажмите «Записать разговор», разрешите микрофон, произнесите фразу 5–10 секунд.
3. Нажмите тот же элемент ещё раз («Остановить»), дождитесь уведомления о сохранении.
4. Откройте «Записи» → новая запись → «Прослушать оригинал». Проверьте звук и длительность.
5. Закройте приложение, откройте повторно: запись должна остаться в журнале.
6. Проверьте импорт готового MP3/WAV/M4A: старый сценарий должен работать.
7. Проверьте отказ в разрешении, очень короткую запись, повторную запись и удаление.

## Честные ограничения

- Запись локальна и НЕ означает, что ASR/диаризация интегрированы. Для расшифровки записанной речи нужен отдельный ML-модуль; загрузка JSON от настоящей модели сохранена из первой версии.
- Длительная запись при уходе приложения в фон не реализована через foreground service; для MVP записывайте при открытом приложении.
- В этой среде полноценная сборка Android APK/запуск на смартфоне не производились. 69 host Java core tests прошли, однако новая запись требует проверки на устройстве.
