# Обновление интерфейса BIMVO

## Изменения по вашему списку

1. Статус, таймер, круговой индикатор уровня и остановка записи закреплены над прокруткой на экранах приложения, включая стартовый экран и профиль.
2. Ползунок, ±10 секунд, переходы к репликам сохранены.
3. Автоматическая обработка после импорта и сохранения записи сохранена.
4. Добавлен круг с радиальными волнами; длина волн зависит от настоящего уровня микрофона.
5. На главной только личные записи.
6. Раздел «Ключевые цитаты» не добавлен.
7. Кликабельные интервалы карты сохранены.
8. Подтверждение удаления сохранено.
9. Русские названия поддерживаются. Меняются название, отображаемое имя и имя принадлежащей приложению локальной копии. Исходный файл, выбранный из внешнего проводника, не переименовывается: приложение хранит копию, а постоянного разрешения на изменение внешнего исходника у него нет. Идентификатор перед именем локальной копии предотвращает совпадения. Переименование во время обработки запрещено; добавлено восстановление после прерывания переименования.
10. Нижний диалог с шестью вариантами сортировки и сохранением выбора сохранён.
11. Убраны лишние подсказки из импорта, карты, экспорта и онбординга. Исправлены сообщения о якобы неподключённых моделях.
12. Описание включает GigaAM CTC, английский Parakeet, Whisper LID, Silero VAD, CAM++, кластеризацию и Qwen.
13. Личный профиль и библиотека отделены от демопримеров. Демо доступны отдельной кнопкой со стартового экрана и из профиля, имеют явную маркировку и не учитываются в личной статистике. Поля вымышленного аккаунта заменены входом в локальную библиотеку.

## Как применить архив изменений

Дождитесь завершения текущей сборки, чтобы не прервать скачивание моделей. Распакуйте содержимое BIMVO_FRONTEND_UPDATE.zip непосредственно в D:\ready\BIMVO_DIARIZATION_ANDROID с заменой файлов. Внутри этого небольшого ZIP сразу лежит папка app. Не создавайте дополнительную вложенную папку проекта. Затем нажмите Run в Android Studio.

Архив обновления не содержит моделей, local.properties или настроек SDK/JDK и не заменяет их. Базовый проект должен быть из ранее выданного BIMVO_DIARIZATION_ANDROID.zip. Полный архив проекта также обновлён для установки с нуля.

## Проверки

- Java 17 target: весь production Java-код компилируется с Android 35, Sherpa 2.0.1, ONNX Runtime 1.24.3 и ранее проверенными production Kotlin-классами. PASS. R и BuildConfig для host-проверки сгенерированы как символы.
- XML ресурсов корректен; используемые строковые ресурсы существуют. PASS.
- 69 assertions исходного ядра, JSON round-trip и 7 проверок SQLite. PASS.
- Новые проверки русских имён, защиты путей и восстановления незавершённого/завершённого переименования с сохранением байтов аудио. PASS.
- Полный APK, внешний вид на телефоне, работа микрофона, касания, навигация и сортировка на Android в этой среде не проверены. На устройстве нужно проверить переходы между экранами во время записи, остановку, круговой уровень, русский rename/воспроизведение/удаление, личную библиотеку и отдельный демо-раздел.
