# BIMVO v3

Обновление вашего проекта BIMVO v2. Сохранены графитовая тема, основные экраны, заставка, вход и навигация. Новая иконка подготовлена из присланной картинки с микрофоном-кристаллом.

**Важно:** это версия с реальным хранением аудио, но без моделей распознавания. Импортированные файлы не получают придуманную расшифровку. Демопримеры отдельно помечены. Это ещё не полное решение для сдачи кейса.

## Открыть в Android Studio

1. Распакуйте архив в отдельную папку, например `D:\Projects\BIMVO-v3`. Не заменяйте старую версию поверх файлов: так у вас останется оригинал.
2. В Android Studio выберите `File -> Open` и откройте **папку BIMVO-v3**, в которой лежат `settings.gradle` и `app`. Не открывайте только папку `app`.
3. Разрешите синхронизацию Gradle. Нужны Android SDK Platform 35 и JDK 17 или совместимый JDK 21. Для первой загрузки инструментов сборки нужен интернет; само приложение его не использует.
4. Выберите свой эмулятор или телефон и нажмите Run.

Загрузчик Gradle сохранён из v2. Версии не менялись: AGP 8.7.3, Gradle 8.10.2, compileSdk 35, targetSdk 34, minSdk 26. Пакет приложения остался `com.bimvo.app`, версия увеличена до `0.3-local`.

## Что добавлено

### Необязательное знакомство
После первого демо-входа открывается окно **Для чего вам BIMVO?** Три сценария: лекции, рабочие встречи, личные разговоры. Каждый ведет к своему окну с тремя блоками пользы. **Пропустить** доступно сразу; кнопка Назад тоже считается пропуском. Выбор или пропуск сохраняется локально и не ограничивает функции. Окно не повторяется при каждом входе.

### Реальный импорт
**Главная -> Загрузить аудио -> Выбрать аудиофайл.** Открывается системный выбор локального аудио. Файл копируется в `files/audio/` внутри хранилища приложения; метаданные сохраняются в SQLite. После перезапуска библиотека восстанавливается из базы. Исходник не перемещается и не удаляется.

Копирование работает отдельно от интерфейса, буфером 64 КиБ. Есть прогресс, отмена, проверка свободного места, обработка пустого или недоступного файла и защита от повторного импорта того же содержимого по SHA-256. Незавершённый импорт не попадает в библиотеку. После аварийного завершения его временные файлы очищаются при следующем запуске.

У загруженного аудио есть страница со сведениями, переименование и удаление **только копии из BIMVO**. Статус: **Не обработано**. Если длительность не удалось прочитать, показывается Не определена, а не придуманное время. Открытие приложения не требует повторного доступа к исходному файлу.

### Библиотека и подсказки
Сохранена сортировка; добавлен поиск по названию файла и тексту **уже существующих** демореплик. Для необработанного аудио поиск по речи пока невозможен. Сводка на главной учитывает записи и известную длительность; демоданные отдельно отмечены.

Переключатель **Подсказки** в профиле включает и скрывает необязательные пояснения на экранах импорта, расшифровки, карты и экспорта. Это не чат и не модель. Его состояние теперь сохраняется между запусками. Важные предупреждения о демо-режиме скрыть нельзя. Лишних пунктов профиля и выборов языка не добавлено.

### Говорящие и время
Каждая реплика имеет стабильный идентификатор, `speaker_id`, `start_ms`, `end_ms` и текст. Карточки, карта диалога и экспорт используют **одни и те же данные**. Время в базе и JSON хранится в миллисекундах. Изменения текста, говорящего и границ демореплик сохраняются в базе, а не только в текущем экране.

Три демозаписи имеют разные расшифровки. На карте показан минутный **демофрагмент**, а не результат обработки вашего аудио. Плеер в демопримере двигает время **без звука**. Импортированные файлы не воспроизводятся в этой версии: задача обновления была сохранить их без обработки.

### Экспорт
Теперь TXT, SRT и JSON действительно записываются через системное окно сохранения. В TXT и SRT есть говорящие и границы реплик. JSON соответствует заданной структуре:

```json
{
  "transcript": [
    {
      "speaker_id": "speaker_1",
      "start_ms": 1250,
      "end_ms": 4380,
      "text": "Добрый день!"
    }
  ]
}
```

**Сейчас можно экспортировать только демопримеры.** Имя такого файла начинается с `DEMO_`. У необработанного аудио кнопка экспорта расшифровки недоступна. Карточка предпросмотра не добавлена.

## Границы этой версии

ASR, диаризация, локальная LLM, запись с микрофона и реальное воспроизведение аудио не подключены. На экране демонстрации обработки прогресс не является измерением работы модели. Выдуманных реплик для импорта нет.

Не удаляйте приложение и не очищайте его данные, если нужны сохранённые в нём копии аудио: они находятся во внутреннем хранилище приложения. Исходные файлы при этом не меняются. Импорт не является фоновой службой с восстановлением после завершения процесса; незавершённый файл нужно выбрать снова.

## Проверки

**В этой среде выполнены:** 69 тестов производственной Java-логики, 110 структурных проверок, проверка точного JSON-контракта и 7 проверок ограничений SQLite. Все 13 Java-файлов прошли синтаксический разбор. Подробности в `qa/TEST_REPORT.md`.

**Не выполнены:** полная сборка APK, Android Lint, запуск на эмуляторе и реальном телефоне. В среде подготовки нет Android SDK, а загрузка Gradle недоступна из-за DNS. Поэтому в архиве нет готового APK и нет утверждения, что приложение прошло проверку на телефоне.

Тесты логики можно повторить с Python 3 и JDK 17+:

```text
python qa/verify_structure.py
python qa/run_core_tests.py
```

Сборка в вашем установленном окружении Windows:

```powershell
.\gradlew.bat :app:assembleDebug
```

После успешной сборки APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Список ручных прогонов для устройства: `qa/MANUAL_TESTS.md`.

## Офлайн-распознавание RU/EN

После диаризации Whisper Tiny определяет язык каждого речевого фрагмента.
GigaAM v3 обрабатывает русский, Parakeet TDT 0.6B v2 int8 — английский.
Фрагменты короче 0,5 секунды и неподдерживаемые метки используют ближайший
определённый язык того же говорящего в пределах 10 секунд, иначе русский.
Для смены языка внутри одного фрагмента нужна отдельная сегментация.
Метки языка сохраняются в плане, а JSON сохраняет существующий контракт.

Перед сборкой разместите модель ERes2NetV2 из checkpoint в
app/src/main/assets/models. Остальные веса и статически слинкованный
Sherpa-ONNX Gradle скачивает и сверяет при первой сборке. Модель Parakeet
добавляет около 661 МБ, Whisper — около 103 МБ. Обработка выполняется офлайн.

Если при упаковке Qwen и Parakeet в один APK Gradle сообщает
`Java heap space`, запустите сборку с одним worker и увеличенным heap:

```powershell
.\gradlew.bat '-Dorg.gradle.jvmargs=-Xmx3584m -Dfile.encoding=UTF-8' :app:assembleDebug --max-workers=1
```
