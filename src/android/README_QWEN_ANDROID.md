Эта ветка содержит исходники, веса моделей, собранный APK и снимок проектных кэшей. Большие файлы и кэши хранятся через Git LFS.

## Получение файлов

Установите Git LFS, клонируйте репозиторий и выполните:

```powershell
git switch codex/offline-audio-summary-ui
git lfs install
git lfs pull
cd BIMVO_MERGED_ANDROID
```

Обычный ZIP с исходниками GitHub может содержать указатели LFS вместо весов. После клонирования проверьте, что файл `app/src/main/assets/models/Qwen3-1.7B-Q4_K_M.gguf` имеет размер 1 282 439 264 байта.

## Сборка

Нужны JDK 17 или 21, Android SDK 35, NDK 28.2.13676358 и CMake 3.31.6. Укажите собственный путь SDK в `local.properties`. Собираются arm64-v8a для телефона и x86_64 для эмулятора.

```powershell
.\gradlew.bat :app:assembleDebug
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`. Полный APK содержит Silero VAD, GigaAM-v3 CTC INT8 и Qwen3-1.7B Q4_K_M; поэтому его размер превышает 1,5 ГБ. Не заменяйте его старым небольшим APK из каталогов APK.

Файл Qwen находится в `app/src/main/assets/models/`. Его наличие включает `BuildConfig.BUNDLED_QWEN`. После установки приложение само копирует модель из APK во внутреннее хранилище и проверяет размер и SHA-256. Отдельный выбор GGUF на телефоне не требуется. Для внутренней копии нужно дополнительно около 1,3 ГБ.

Кэши `.gradle`, `llm/.cxx`, `app/build`, `llm/build` включены по запросу как снимок сборки. Они содержат пути исходного компьютера и не являются переносимой заменой SDK/NDK: на другом компьютере Gradle может пересоздать их.

## Пользовательский сценарий

- При записи отображаются таймер, уровень микрофона и остановка. После импорта или сохранения распознавание запускается автоматически.
- Вверху записи отображаются статус и проценты. Плеер поддерживает перемотку и переход на 10 секунд. Карта диалога запускает аудио с начала выбранной реплики.
- Меню записи в библиотеке позволяет переименовать её на русском и удалить локальную копию аудио, расшифровку и сохранённый конспект.
- Большая кнопка «Конспект» доступна после готовности расшифровки. Qwen обрабатывает текст локально. Счётчик токенов не показывается.
- Готовый конспект сохраняется за записью и повторно не генерируется. Доступны копирование и экспорт в UTF-8 TXT. Редактирование расшифровки не пересоздаёт уже сохранённый конспект.
- Демопримеры отделены от пользовательских записей на главной. Встроенной диаризации в этом конвейере пока нет; `speaker_unknown` обозначается как «Речь».

## Ограничения

Qwen использует CPU, контекст 1024 токена и до 192 токенов ответа. Длинная расшифровка отклоняется без обрезания: автоматическое сведение частей ещё не реализовано. Генерация отменяется при закрытии диалога или уничтожении Activity. Предварительный запрет по объёму ОЗУ и числу параметров убран; остаётся остановка при критическом дефиците памяти. Android всё ещё может завершить процесс при её нехватке.

Проверки: изменённые Java-классы компилируются, XML ресурсов корректен. Нативный движок проверен для arm64-v8a и x86_64. Последняя сборка в терминале пользователя завершилась BUILD SUCCESSFUL. Полный пользовательский сценарий на физическом телефоне после последних UI-изменений требует проверки.
