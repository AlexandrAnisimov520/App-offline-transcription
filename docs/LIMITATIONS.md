# Ограничения

- Диаризация ограничена 10 минутами аудио за один проход и доступной RAM. Количество говорящих определяется автоматически, но может отличаться от истинного.
- Смешанная монофоническая речь не разделяется на независимые аудиодорожки. Overlap-интервалы сохраняются; неоднозначные ASR-чанки получают speaker_unknown.
- Отмена обрабатывается до/после native diarization process и между ASR-чанками; сам native process не прерывается callback-ом.
- Старый этап анализа остаётся для совместимости ASR-границ, поэтому есть дополнительная вычислительная стоимость.
- Веса должны быть подготовлены до установки. Большой APK и рабочие PCM требуют свободного места.
- Переименование внешнего файла возможно только через поддерживающий операцию DocumentsProvider; перед ним проверяется SHA исходника. Внутренняя копия аудио сохраняется.
- Короткие, тихие, шумные реплики и одновременная речь остаются сложными случаями. WER и DER — разные метрики; результаты прежних конфигураций не приписываются новой CAM-конфигурации.
