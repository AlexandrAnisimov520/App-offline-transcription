# Установка и использование

1. Соберите APK по README или скачайте предоставленный APK команды.
2. Передайте файл на Android, разрешите установку для выбранного источника и установите.
3. Откройте BIMVO, выберите язык новых записей: RU, English или AUTO.
4. Запишите аудио либо импортируйте локальный файл. После сохранения расшифровка запускается автоматически.
5. Используйте ползунок, ±10 секунд и карту для перехода к моментам записи.
6. В библиотеке доступны сортировка, поиск, переименование и удаление. Демопримеры открываются отдельно из профиля.
7. Сохраните JSON/TXT/SRT, аудиофайл или конспект Qwen. Для внешнего исходника переименование требует выбора того же файла и поддержки Android-провайдером.
8. Для проверки автономности включите авиарежим. Сохраняйте исходные записи и экспорт важных результатов перед удалением приложения.
